# kdutify-loader

This monorepo contains compiler plugins for autoloading Kdutify components and configuring styles.

- [Lahm plugin](./packages/lahm-plugin)
- [Webpack plugin](./packages/webpack-plugin)

The old [`kdutify-loader`](https://npmjs.com/package/kdutify-loader) package has been renamed to [`webpack-plugin-kdutify`](https://npmjs.com/package/webpack-plugin-kdutify) for Kdutify 3.
